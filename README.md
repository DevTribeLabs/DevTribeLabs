# DevTribe Labs

Tools for people who run their business on HighLevel and other CRMs.

## What we build

- **[iBluSend](https://iblusend.com)** — native iMessage (blue bubbles) for GoHighLevel, HubSpot, Close and Pipedrive, plus Android SMS lines on your own carrier plan.
- Custom web apps, AI automation and growth systems — [devtribe.ai](https://devtribe.ai)

## Free and open source

- **[devtribe-skills](https://github.com/DevTribeLabs/devtribe-skills)** — agent skills and output styles for Claude Code and Codex. MIT.
